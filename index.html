📖 Template Syntax & Placeholders Guide

1. Dropdown Picker with Custom Write-In {Label: Option 1 / Option 2 / Option 3}
Example: {Brand: Breg / DonJoy / Ossur / DJO}
Example: {Size: Ped./XXS/XSmall/Small/Med/Large/XL/2XL/3XL/4XL}
Generates a clean dropdown menu in the customizer with an automatic "Custom Write-In..." option.
2. Fill-in-the-Blank Text Field [Field Name] or ______
Example: [Thigh Circumference] or [Diagnosis]
Displays a text input box in the customizer to type values into the note.
3. Optional Phrase Toggle Button {+ Button Label: Full phrase text to insert}
Example: {+ Achilles Wedge: Achilles wedge was fit to inner liner of boot for gradual reduction of contracture following surgery.}
Example: {+ Parent Present: Parent was present during the appointment.}
Generates a 1-click toggle pill button in the customizer. When ON, the phrase is included in the note.
4. Office Location: North/South (Toggles North or South office)
5. Side / Laterality: Left/Right or L/R (Toggles Left, Right, or Bilateral)
6. Pronoun Conversions: he/she, his/her, him/her (Converts based on patient sex)
